# Skill 变更验证

## 冻结

行为修改运行基线与候选对照：触发和路由、输入范围、权限和确认点、工作流及失败处理、完成声明，以及影响行为的脚本、模板或默认参数。纯排版、错字和无行为变化的链接修复只做静态检查；不能确定时按行为修改验证。

运行前冻结被测 Skill、唯一主要变化、预期改善、验收条件、基线与候选身份，以及用户消息、来源、个人上下文、工具权限和上下文继承方式。至少覆盖典型请求、目标失败和负向对照三个真实场景；写入型补充无增量、范围确认、来源只读、目标页选择及写入后查询复用。

不得根据候选输出修改事实或验收标准。需要修复时结束本轮，建立新候选后重跑。

## 对照

- 使用不继承开发对话、历史结论或另一候选输出的独立 subagent。仅提供任务必需的 Skill、冻结来源和工具权限，不提供组别、参考答案、评审标准或修改理由。
- 除冻结的被测变化外，模型、用户消息、来源、个人上下文、工具和初始文件状态一致；出现无法解释的输入差异时停止比较并重跑。
- 写入只在隔离的临时 vault 或 fixture 中进行；父 vault、开发仓库和另一候选不可写。默认禁用 web、额外 MCP、记忆和其他 Skill；确有需要时对两组提供相同能力并记录。
- 保留完整消息、回答、文件 diff 和机械指标。

## 评审

由未参与生成或修复的独立 subagent 评审，不继承开发对话。以匿名 ID 替换版本、会话和工作区身份，先逐个评审，必要时再成对比较。只提供候选完整对话、知识 diff、冻结意图、允许来源和机械指标。

分别判断来源忠实度、事实与推断边界、知识增量、目标页与来源关系、后续复用、表达明确性和个人偏好匹配。篇幅、术语数量、格式复杂度和单一总分不能证明改善。

分歧影响接纳时，用两个独立会话交换展示顺序复核；结论随顺序变化则记为不确定。

## 接纳

以下任一情况判为失败：

- 关键事实无依据、错误归因或把跨领域类比当直接证据。
- 未经确认扩大写入范围，违背被测 Skill 的来源只读要求，或修改父 vault、开发仓库及无关文件。
- 无契约允许的变化却制造修改；来源维护超出相关链接和必要 header。
- 损坏知识、来源、链接或检索入口；负向对照在事实、来源、写入或复用上退化。
- 生成或评审接触禁止输入，匿名失效，或两组存在未解释的输入差异。

文件越界、未授权网络访问和真实工作区写入单独记为隔离失败；只能保留行为线索，不声明验证通过。

仅在无失败、目标场景有可解释改善、典型和负向场景不退化，且证据支持预期机制时接纳。证据不足、评审不稳定或仅干跑推演时标为未验证；候选是否暂时保留由用户决定，不表述为有效。

## 记录

记录版本身份、修改目标、冻结场景与实际输入、完整回答与 diff、机械指标、失败检查、匿名评审及必要复核、已证明和未覆盖范围。

明细留在临时目录，不写入父 vault、开发计划或日志；稳定、脱敏且可迁移的场景才进入仓库 fixture。
