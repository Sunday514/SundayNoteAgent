# Query

已有上下文不足、历史经验可能改变下一步时，先定向查阅再决定，尤其是在准备重复同类尝试或投入高成本验证前。简单明确的操作直接完成；已有适用方法及依据且条件未变时直接复用。

1. 确认目标 Vault、任务范围与环境授权，使用环境提供的搜索和读取工具。工作任务不补读个人来源，文件可见不等于获准；范围不明先确认，不读取正文猜测归属。未经明确授权不读取或修改 `个人写作/`，链接、索引和符号链接不扩大权限。
2. 从已有获准入口定位相关小节；项目入口未知时按需读 `项目维护/项目总览.md`。用当前症状、变更或待区分的解释搜索获准路径、标题和正文，只读解决疑点所需的内容。查方法优先看 Wiki；项目记录或 Raw 只提供泛相关信息时，继续定位相关 Wiki。找到可用方法、确认不适用或相关范围无命中即停。工具不可用或拒绝访问时说明限制，不绕过权限或自动安装依赖。
3. 对照当前输入、环境与约束核对方法。方法可能影响下一步，而条件或依据不清、有证据冲突或纠错线索时，只补读相关来源小节，优先核对纠正与反例。方法适用且能改变行动或区分解释时，将它落实为下一步。候选方法只作待验证假设；已被推翻的方法停止采用。
4. 事实优先查 Raw；需要核验时按明确入口补读获准的资料、项目记录和时间记录（包含年度、专项），不把 Wiki 缺页当作没有证据。不递归展开引用。仅在事实冲突、关键细节缺失或明确要求精确复核时尝试定位获准的本机原始 Agent 轨迹；找不到就说明限制，不否定已有 Raw。
5. 只输出当前问题或决策需要的方法、条件和必要来源，不复制长篇检索结果；知识不可达时说明影响，继续可独立开展的工作。依据实际读取内容回答，不复述来源结构，不展示 `%% agent ... %%`。仅在诊断需要或用户要求时说明候选筛选过程；不推断未确认的个人偏好或计划。

全程只读，不修改知识文件或运行状态，不自动触发 Ingest、Lint 或 Audit。产生稳定新知识时只提出写入建议。
