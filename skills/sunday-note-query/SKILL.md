# Query

1. 工作请求只使用工作来源及统一 Wiki，不读取个人上下文、个人来源或写作。个人请求需要了解长期项目、历史决策、目标、取舍或表达偏好时，再按需读取 `个人上下文.md`；普通知识检索直接提取问题线索。
2. 个人上下文已有准确 Wiki、Raw 或 Routine 入口时直接读取；否则提取 3–8 个名称、日期、术语或完整短语，运行 `scripts/query_search.py <关键词...>`，每个短语作为一个参数。
3. 从搜索结果按子主题、相关性和重要性选择不超过 3 个 Wiki，逐页读取，证据足够时停止。保留候选、精读后排除页和最终证据页的区分。
4. 需要细节、项目验证、来源限制或冲突核对时，只沿 Wiki 直接链接补读当前权限范围内的 Raw / Routine；个人可引用工作，工作不补读个人来源。不递归追踪或批量确认链接存在性。
5. 依据实际读取内容回答并保留相关证据，不复述来源结构，不展示 `%% agent ... %%`。仅在诊断需要或用户要求时说明候选筛选过程；不推断未确认的个人偏好或计划。

全程只读，不修改知识文件或运行状态，不自动触发 Ingest、Lint 或 Audit。产生稳定新知识时只提出写入建议。
