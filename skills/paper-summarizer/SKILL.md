# 论文总结

写出让读者真正理解论文的中文总结：不仅知道结论，还能理解方法为何有效、证据支持到哪里，以及哪些判断仍不确定。篇幅随内容复杂度调整，不用固定章节、条目数量或模板填充。

## 阅读与理解

使用当前可用的 PDF 读取能力；需要本地提取时可用 `pdftotext -layout`，查看图表和公式可用 `pdftoppm` 渲染相关页。工具是手段，不固定解析器，也不自动安装依赖或上传本地论文到外部服务。

通读正文，结合图表与支撑主要论断的附录建立完整理解，不只改写摘要。长文分段读，避免工具输出截断造成漏读；双栏错序、扫描页、缺字或公式失真时回看页面，必要时使用可用 OCR。仍无法可靠读取的部分明确说明，不把局部阅读称为完整精读。

围绕论文自己的问题和贡献组织解释：交代问题与约束、相对已有工作的变化，讲清关键机制、假设、流程及必要公式；分析证据如何支持结论，包括关键比较、实验条件、指标、消融、反例和适用边界。理论论文重在假设与论证，综述重在观点关系与分歧，不强套实验章节。

区分作者主张、实际证据和你的分析；评价具体到证据，既不默认套主流框架，也不为追求独特而编造贡献。术语首次出现时解释，段落承担论述，列表和表格只用于真正有助于比较的地方。

## 写作与组织

开头先讲主要贡献和发现，再按读者理解所需的顺序展开。用简短、内容明确的小标题组织长文，每段围绕一个要点；不用固定章节，但要有清晰主线。保留解释机制和判断结论所需的细节，合并重复限定，局限集中展开而不在各段反复声明。

正文直接讲论文及其依据，不叙述检索、阅读、核验、工具操作、重处理或任务计数过程。推导用于解释论文的机制与论证，不写成自己的思考流水账。只有影响结论可信度的阅读缺口才在正文简要说明，其余处理限制放交付回复，不另设核验日志章节。

## 来源与配图

书目信息简洁保留标题、主要作者、版本日期和原文链接，不铺陈完整作者名单、精确时间及访问记录；信息缺失就说明未明确，不把 PDF 文件属性当成发表信息。关键结论、数字和容易误解的论断保留必要的页码、章节或图表定位，核对指标方向、单位和比较条件。同源连续论述合并在段末或节末引用，表格统一标明来源，避免逐句插链接；合并后仍须看得出依据对应哪个结论。外部补充与论文原文分开，不以二手介绍替代原文。

选择对机制或证据有解释价值的原图，插在对应论述附近并说明读图重点、原图号和页码；数量由实际需要决定，不凑配图。提取图片或渲染后裁剪均可，矢量图可直接渲染页面；查看最终图片，保留必要图例、坐标、标注和清晰度。不要用生成图片替代论文证据；无法得到可读图时说明，不插空链接。

图注优先解释图意，沿用原图号，避免另编一套编号。来源、署名和许可简洁保留，相同信息可集中说明；不把下载、裁剪或核验过程写成长图注，许可要求的修改说明仍须保留。

## 保存与交付

默认保存到 vault 的 `10_原始材料/工作/论文总结/<论文标题>.md`，个人论文改用 `个人`；图片放 `assets/<工作或个人>/figures/<paper-slug>/`，仅保存实际引用的图片并使用相对链接。用户指定只读或仅对话回答时不写入 vault。

来源链接使用已核实的稳定在线地址，或指向 vault 内长期保存原文的相对链接；不引用 vault 外文件、临时附件或 `.import_files` 中的缓存，不为生成链接自动复制 PDF。没有可用链接时保留可核实的论文身份及页码、章节等定位信息，并说明链接缺失。

目录名使用简短安全的论文标识，重名先核对论文与版本，不覆盖其他材料或用户已有笔记。临时提取文本与页面放临时目录；无需额外 metadata、证据 JSON 或状态文件。不直接修改跨论文 Wiki 或 Project。

交付前回核核心论断和数值、重要遗漏、来源与图片链接，实际查看所插图片；通读标题层级与段落衔接，删除过程说明、重复限定和空泛表述，检查编号连续。报告尚未读清或无法验证的部分；格式整齐不等于内容已经核实。
