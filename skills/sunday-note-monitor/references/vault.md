# Vault 文档入口

一致性或知识检查涉及项目背景时按需读取本页；主 Agent 无需预读。以下均相对委托中的 Vault，先确认路径存在。

- `30_知识库/索引.md`：稳定知识入口；按主题查已有方法、限制和来源。
- `23_项目复盘/`：项目架构、计划、日志、Proposal 和业务场景。代码变化除了核对仓库 README/docs，还应检查受影响的项目说明是否承接。
- `10_原始材料/`：外部资料的忠实记录；`20_每日记录/`、`21_每周记录/`、`22_每月记录/`：个人活动证据。它们不是自动高于新决定的规则。
- 代码说明当前实现，设计文档说明约定；历史日志说明当时状态，不按当前实现重写。会话摘要只作来源索引，不作独立事实。默认不读取 `40_个人写作/`。
